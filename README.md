# Laboratorio de Creadores Digitales

Narrativas audiovisuales y redes sociales, en varias sesiones. La fase 1 entrena el ojo fotográfico (ángulos, exposición, contraste y composición). Requiere cámara y edición en el celular.

Forma parte de [PROYECTO LEARNING](https://github.com/fabianbauttt/PROYECTO-LEARNING), del Prof. Fabián Bautista G.

## Cómo usarlo

- **Jugar:** <https://fabianbauttt.github.io/Laboratorio-Creadores-Digitales/>
- **En local:** abre `index.html` en el navegador. No necesita instalación.

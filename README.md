# Laboratorio de Creadores Digitales

Narrativas audiovisuales y redes sociales, en varias sesiones. La fase 1 entrena el ojo fotográfico (ángulos, exposición, contraste y composición). Requiere cámara y edición en el celular.

Forma parte de [PROYECTO LEARNING](https://github.com/fabianbauttt/PROYECTO-LEARNING), del Prof. Fabián Bautista G.

## Cómo usarlo

- **Jugar:** <https://fabianbauttt.github.io/Laboratorio-Creadores-Digitales/>
- **En local:** abre `index.html` en el navegador. No necesita instalación.

## Panel docente

El mapa de rodaje tiene un botón **Panel docente**, protegido con contraseña; se oculta al abrir un módulo. Incluye el resumen de las cuatro fases, las respuestas de todos los retos, una guía de uso en clase, preguntas de reflexión, una rúbrica para las misiones y una bitácora de rodaje imprimible.

El contenido está cifrado en `panel-docente-datos.js`, así que no se puede leer abriendo el código fuente. `panel-docente.js` es el módulo común que muestra el panel. Para editar el material, ver la herramienta del panel docente en [PROYECTO-LEARNING](https://github.com/fabianbauttt/PROYECTO-LEARNING/tree/main/herramientas/panel-docente).
